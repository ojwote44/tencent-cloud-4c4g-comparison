## 带宽是4核4G最容易买错的一项

1Mbps约等于128KB/s。一个2MB的首页，1M带宽理论上传完要16秒，实际还有并发和网络开销，只会更慢。很多人买完4核4G觉得「配置不低怎么还是慢」，问题往往出在带宽上。

- 纯接口、后台管理：1–3M够用
- 有图片的前台页面：5M起步
- 视频、软件下载：别用固定带宽，走对象存储加CDN，或者改成按流量计费
